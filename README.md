# Прозрачная вакансия (Канткод — онлайн-отбор)

Прототип сервиса для анализа вакансий Калининградской области (регион 39, портал «Работа в России») и формирования JSON-отчёта с вопросами и уточнениями для редактора.

## Архитектура и точка входа
- Точка входа: main.py (запуск рабочего режима, режима по расписанию и проверочного режима).
- fetcher.py — загрузка вакансий по API с пагинацией (минимум 2 страницы), обеспечение уникальности по ID вакансии в отчёте и сохранение последнего успешного отчёта при сбое API; также загрузка локального JSON.
- analyzer.py — проверка полей (должность, обязанности, требования, оплата, график, место работы, тип занятости) с использованием LLM (OpenAI-совместимый API) и резервным правилосодержащим анализатором.
- scheduler.py — запуск рабочего цикла по расписанию.
- config.py — загрузка настроек из переменных окружения (.env).

## Настройка и запуск без платного аккаунта
1. Установите зависимости:
   pip install -r requirements.txt

2.2. Скопируйте .env.example в .env:
   - Для запуска с ИИ можно использовать бесплатный токен GitHub Models (создаётся в разделе Fine-grained tokens на https://github.com/settings/tokens с правом Models: Read-only), либо любой другой OpenAI-совместимый API / локальный Ollama.
   - Укажите в .env параметры LLM_API_KEY, LLM_BASE_URL (https://models.github.ai/inference) и LLM_MODEL (по умолчанию используется openai/gpt-4o-mini).
   - Проверочный режим запускается и без API-ключа (автоматически активируется встроенный fallback-анализатор). Ключи в репозитории не хранятся.

## Команды запуска
- Проверочный режим на локальном JSON:
  python main.py --mode check --input sample_data/test_vacancies.json --output output/check_report.json

- Рабочий режим (разовый ручной запуск с API региона 39):
  python main.py --mode live --max-vacancies 20 --output output/report.json

- Рабочий режим по расписанию (интервал в минутах):
  python main.py --mode schedule --interval 60 --output output/report.json

## Формат выходного JSON-отчёта
Отчёт содержит метаданные запуска (generated_at, mode, source, total_vacancies) и массив vacancies:
- vacancy_id — идентификатор вакансии.
- vacancy_url — ссылка на карточку вакансии (если есть).
- issues — массив замечаний ([], если замечаний нет). Каждый элемент содержит:
  - issue_type — "пропуск", "неоднозначность" или "противоречие";
  - topic — тема проверки (оплата, график, обязанности, требования, место работы, тип занятости, название должности);
  - field — поле источника;
  - quote — цитата/значение (пустая строка при пропуске; оба значения при противоречии);
  - problem — описание проблемы;
  - recommendation — конкретный вопрос/уточнение для работодателя.
